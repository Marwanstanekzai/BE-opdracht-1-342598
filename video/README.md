# Video Instructies Voor Inlevering

Volgens de opdracht vereisten dient er een schermopname (video) gemaakt te worden van de werkende functionaliteiten.

## Hoe te maken:
Gebruik **Windows Game Bar** (`Win + G`) of een andere schermopnamesoftware.

## Eisen aan de video:
1. **Browser laten zien**: open de applicatie in de browser (`http://127.0.0.1:8000`).
2. **Geen code laten zien**: alleen de werking in de browser en phpMyAdmin.
3. **Maximale duur**: maximaal 60 seconden per actie.
4. **Scenario's laten zien**:
   - Inloggen als `magazijnmedewerker@gmail.com` (wachtwoord: `password`).
   - Overzicht Magazijn Jamin tonen (gesorteerd op barcode oplopend).
   - Mintnopjes aanklikken (vragteken `❓`) -> Levering Informatie tonen (leverancier Venco + leveringen).
   - Winegums aanklikken (vragteken `❓`) -> Melding "geen voorraad" + 4 seconden redirect.
   - Zoute Ruitjes aanklikken (rode `❌`) -> Overzicht Allergenen tonen.
   - Cola Flesjes aanklikken (rode `❌`) -> Melding "geen allergenen" + 4 seconden redirect.
   - **phpMyAdmin**: kort de 6 tabellen, de datastructuur/relaties en gevulde data tonen in phpMyAdmin.

Plaats het opgenomen videobestand in deze `video/` map (bijv. `demo_magazijn.mp4`).
